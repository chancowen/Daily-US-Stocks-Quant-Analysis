# Daily US Stocks Quant Analysis

Auto-updated daily by an automated quant pipeline (4-pillar score: Momentum / Risk /
Fundamentals / Valuation, with RSI, MACD, relative strength vs SPX, volume confirmation,
analyst target & revision layer, backtest and correlation/concentration checks).

- `index.html` — latest interactive dashboard (served via GitHub Pages)
- `widget_card.html` — compact summary card
- `data/` — latest dashboard CSV and dated Excel signal workbook

Data source: Yahoo Finance. Not investment advice.
